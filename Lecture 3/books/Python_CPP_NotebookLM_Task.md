# 📘 Learning Task: Mastering Python & C++ with NotebookLM
### A 3–4 Week Self-Paced Programming Challenge for Mixed-Level Learners

---

## 🎯 Task Overview

You will be given **two programming books** — one for **Python** and one for **C++**. Using **NotebookLM** as your AI study partner, you'll explore both languages, complete tiered tasks (Basic → Advanced), and build real understanding — not just copy-paste code.

This task is designed so that:
- **Non-CS background students** can build solid foundations without feeling lost.
- **CS background students** get pushed into advanced, portfolio-worthy challenges.
- Everyone stays engaged through variety: coding, audio learning, mind maps, quizzes, and creative mini-projects.

---

## 📚 Materials Provided

| Resource | Purpose |
|---|---|
| 📕 Python Book (PDF) | Core reference for Python track |
| 📗 C++ Book (PDF) | Core reference for C++ track |
| 🧠 NotebookLM | Your AI study assistant (upload both books as sources) |

> **Setup Step (Day 0):** Upload both books into a **new NotebookLM notebook**. Create two sources named clearly: `Python_Book` and `Cpp_Book`. This keeps citations accurate when you ask questions later.

---

## 🧭 How This Task Is Structured

The task runs in **4 weeks**, split into a **Foundation Track** (for everyone) and a **Branch Track** (choose based on your background/confidence). Each week ends with a **Checkpoint Deliverable**.

```
Week 1 → Orientation + Core Syntax (Both Languages)
Week 2 → Applied Practice + First Mini-Project
Week 3 → Advanced Concepts + Comparative Thinking
Week 4 → Capstone Build + Peer Teaching
```

---

## 🗓️ WEEK 1 — Foundations & Getting Comfortable

**Goal:** Get familiar with syntax, mindset, and how to *use NotebookLM effectively* (not just as a chatbot, but as a study engine).

### Step 1: NotebookLM Orientation (Required for ALL students)
Using your uploaded books, do the following inside NotebookLM:

1. **Generate an Audio Overview** for each book (Python & C++) — listen during a commute or break. This is especially helpful for non-CS students to hear concepts explained conversationally before reading code.
2. **Generate a Study Guide** for Chapter 1–2 of each book.
3. **Ask NotebookLM 5 questions** about anything confusing (e.g., "Explain pointers like I'm new to programming" for C++, or "What is a list comprehension and why use it?" for Python).
4. **Create a Mind Map** in NotebookLM comparing the *basic building blocks* of both languages (variables, loops, conditionals, functions).

### Step 2: Basic Tasks (Everyone completes these)

| # | Task | Python | C++ |
|---|---|---|---|
| 1 | Print a formatted personal profile (name, age, hobby) | ✅ | ✅ |
| 2 | Write a program using loops to print a number pattern | ✅ | ✅ |
| 3 | Take user input and perform basic arithmetic | ✅ | ✅ |
| 4 | Write a function that checks if a number is prime | ✅ | ✅ |

> 💡 **Interest Hook:** Instead of plain "print numbers 1–10," personalize it — e.g., print a **countdown for your own event** (birthday, exam, holiday) in both languages.

### 📌 Week 1 Checkpoint Deliverable
Submit:
- Audio overview reflection (3–4 sentences: what did you learn from listening vs. reading?)
- Screenshot or export of your Mind Map
- 4 basic task code files (2 Python + 2 C++)

---

## 🗓️ WEEK 2 — Applied Practice & Branching Begins

Now students **choose a branch** based on comfort level. You can switch branches later — this isn't a locked track.

### 🌱 Branch A: Non-CS / Beginner-Friendly Track
Focus: Building confidence, understanding *why*, not just *how*.

| Task | Description |
|---|---|
| Guided Debugging | NotebookLM will explain 3 intentionally broken code snippets (provided by instructor) — ask it "what's wrong with this code and why?" |
| Concept Translator | Pick 3 confusing terms (e.g., "class," "pointer," "loop") and use NotebookLM to generate simple analogies. Write them in your own words. |
| Mini Project: **Unit Converter** | Build a simple converter (e.g., Celsius↔Fahrenheit) in both Python and C++ |

### 🚀 Branch B: CS Background / Advanced Track
Focus: Depth, comparative reasoning, efficiency.

| Task | Description |
|---|---|
| Comparative Analysis | Ask NotebookLM: "How does memory management differ between Python and C++?" Write a 150-word summary citing the books. |
| Mini Project: **Contact Book (CRUD)** | Build a command-line contact manager with add/edit/delete/search in both languages |
| Code Optimization Challenge | Take your Week 1 prime-number checker and optimize it for performance in C++; discuss Big-O with NotebookLM |

### 📌 Week 2 Checkpoint Deliverable
- Mini-project code (both languages)
- A short **NotebookLM-generated quiz** (5 questions) that YOU create by asking NotebookLM to quiz you on Week 1–2 material, plus your answers
- Reflection: "What was harder — Python or C++ this week, and why?"

---

## 🗓️ WEEK 3 — Advanced Concepts & Cross-Language Thinking

Everyone attempts these, but depth expectations differ by branch (see rubric).

### Core Advanced Topics to Explore via NotebookLM
Ask NotebookLM to explain each using **both books as sources**, then attempt the paired task:

| Concept | Python Task | C++ Task |
|---|---|---|
| **Object-Oriented Programming** | Build a `Student` class with attributes + methods | Build a `Student` class using constructors/destructors |
| **File Handling** | Read/write a `.txt` file of student grades | Read/write the same using `fstream` |
| **Error Handling** | Use `try/except` for invalid input | Use `try/catch` for the same scenario |
| **Data Structures** | Implement a stack using a list | Implement a stack using an array or `std::stack` |

### 🎨 Creative Interest Booster (All Students)
Use NotebookLM to **generate a "debate script"**: ask it to argue *"Python vs C++: which is better for beginners?"* from both sides using evidence from the books. Read it, then **write your own verdict** (150 words) — this builds critical thinking and keeps things fun.

### 📌 Week 3 Checkpoint Deliverable
- 4 code tasks (OOP, file handling, error handling, data structure) — both languages
- Debate reflection write-up
- One NotebookLM-generated **audio overview** of your own notes (yes — upload your own summary as a source and generate audio from it!)

---

## 🗓️ WEEK 4 — Capstone Project & Peer Teaching

### Capstone Project (Choose ONE, built in BOTH languages)
Pick a project matching your branch:

**Beginner-Friendly Options:**
- 🎲 Number Guessing Game with score tracking
- 📝 Simple To-Do List (console-based)
- 🧮 Basic Calculator with a menu system

**Advanced Options:**
- 📊 Student Grade Management System (OOP + file handling + error handling combined)
- 🏦 Mini Banking System (deposit/withdraw/balance, with data persistence)
- 🔐 Simple Password Strength Checker with custom validation logic

### Required NotebookLM Use for Capstone
1. Generate a **project plan/outline** by asking NotebookLM to suggest a structure based on concepts from both books.
2. Generate a **FAQ document** of likely questions/bugs for your chosen project.
3. Create a **final Mind Map** connecting everything you learned across both languages.

### 🎤 Peer Teaching (Fun + Retention Booster)
Record a 2–3 minute video or do a live 5-minute explanation to a classmate:
> "Here's what I built, and here's one thing Python does better and one thing C++ does better."

### 📌 Final Deliverable Package
- Capstone project code (Python + C++)
- Final Mind Map export
- Peer teaching video/notes
- Completed **Self-Assessment Rubric** (see below)

## 💡 Tips for Staying Motivated

- 🎧 Listen to NotebookLM audio overviews like a podcast — don't just read.
- 🔄 Switch branches anytime — this isn't a race, it's about real learning.
- 🤝 Pair up: one CS-background + one non-CS student can help each other (CS explains logic, non-CS often asks the "why" questions that deepen everyone's understanding).
- ❓ When stuck, ask NotebookLM: *"Explain this concept as if I've never coded before"* — it adjusts tone based on how you prompt it.
- 🏆 Celebrate small wins — first working program in a new language is a real milestone!
