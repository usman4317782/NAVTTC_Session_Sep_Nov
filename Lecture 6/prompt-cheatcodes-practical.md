# Practical Assessment: AI Prompting "Cheat Codes"

**Course Module:** Professional Prompt Engineering
**Reference Material:** 32 Ultra-High-Leverage Modifiers (T-Minus AI)
**Assessment Type:** Hands-On Practical (No written answers — run the prompts)
**Duration:** 90 minutes

---

## Purpose

This is a **hands-on practical**. There are no questions to answer on paper. Every task below gives you a **ready-to-use prompt**. Copy each prompt **as-is** into your AI tool (ChatGPT, Claude, etc.), run it, observe the output, and compare it against the "What to Observe" note under each task. This builds real muscle memory for using modifiers in professional work.

---

## Instructions for Students

1. Open your AI chat tool.
2. Copy each prompt **exactly as written** (including the `/MODIFIER` tags) and paste it in.
3. Run it. Read the output.
4. Check the **"What to Observe"** line — confirm the output actually behaves that way.
5. Move to the next task. Do all 15 tasks in order.
6. Save your chat outputs (screenshot or export) as your submission.

## Section A — Speed & Formatting

### Task 1
```
/TLDL: Summarize the following into 5 key bullet lines only:

"Our Q3 sales meeting covered declining conversion rates in the EU region, a proposed fix involving a new checkout flow, budget concerns from finance regarding a $200k ad spend increase, and a leadership disagreement on whether to prioritize mobile app redesign or the checkout fix first. The meeting ended without a final decision, and a follow-up was scheduled for next week."
```
**What to Observe:** Output should be exactly 5 bullets, no extra commentary.

### Task 2
```
/EXEC SUMMARY /BRIEFLY: We are considering expanding our SaaS product into the Southeast Asian market. Give me a CEO-ready synopsis in under 100 words.
```
**What to Observe:** Should read like something you'd forward to a CEO — no fluff, no filler intro.

### Task 3
```
/FORMAT AS TABLE: Compare Notion vs Trello for a 10-person startup team, across Pricing, Ease of Use, Collaboration Features, and Scalability.
```
**What to Observe:** Output must render as an actual table, not a bulleted list.

### Task 4
```
/CHECKLIST: Give me everything I need to do to launch a personal portfolio website this week.
```
**What to Observe:** Should be checkbox-style, actionable, in doable order.

## Section B — Persona & Tone

### Task 5
```
/ACT AS a Michelin-star Chef /TONE Urgent: Walk me through how to fix a béarnaise sauce that has just split, in real time, as if I'm mid-cooking and panicking.
```
**What to Observe:** Tone should feel urgent and instructional, in-character as a chef, not a generic recipe blog answer.

### Task 6
```
/DEV MODE: Give me a Python function that validates an email address using regex. Code only, no explanation.
```
**What to Observe:** Output should be code-only — no paragraph explanations before or after.

### Task 7
```
/PM MODE: We are launching a mobile app feature in 6 weeks with a 3-person dev team. Give me timelines, resource allocation, and key risks.
```
**What to Observe:** Should look like a project plan — timeline, resources, risks clearly separated.

### Task 8
```
/AUDIENCE Beginners /JARGON-FREE: Explain what an API is.
```
**What to Observe:** No technical jargon; explanation should be accessible to a true beginner.

## Section C — Deep Logic & Reasoning

### Task 9
```
/FIRST PRINCIPLES: Why do rockets need multiple stages instead of one big engine? Build the explanation from fundamental physics up.
```
**What to Observe:** Answer should build from basic principles (mass, fuel, thrust) rather than just stating facts.

### Task 10
```
/CHAIN OF THOUGHT /EVAL-SELF: A store sells apples in bags of 4 and 6. What is the smallest number of apples a customer cannot buy using any combination of these bags? Show your reasoning step-by-step, then critique your own final answer for errors.
```
**What to Observe:** Should show visible step-by-step logic, then a separate self-critique section at the end.

### Task 11
```
/SYSTEMATIC BIAS CHECK: Review this statement for bias: "Remote workers are less productive than in-office employees." Identify any assumptions, missing context, or one-sided framing.
```
**What to Observe:** Should flag assumptions and present balanced counter-considerations, not just agree or disagree.

---

## Section D — Analysis & Strategy

### Task 12
```
/SWOT /FORMAT AS TABLE: Do a SWOT analysis for a small local coffee shop considering opening a second location in a nearby city.
```
**What to Observe:** Four clear quadrants (Strengths, Weaknesses, Opportunities, Threats), in table format.

### Task 13
```
/MULTI-PERSPECTIVE: Should companies adopt a 4-day work week? Give me 3 distinct viewpoints: Economic, Social, and Ethical.
```
**What to Observe:** Three clearly separated viewpoints, each internally consistent and distinct from the others.

### Task 14
```
/PITFALLS /METRICS MODE: We're planning to switch our entire customer support to an AI chatbot. What could go wrong, and what KPIs should we track to know if it's working?
```
**What to Observe:** Should include both a risk/pitfalls list AND a separate KPI/metrics list.

## Section E — Advanced Control (God Mode)

### Task 15
```
/ROLE: Senior Cybersecurity Consultant
/TASK: Assess whether a 50-person fintech startup should adopt a zero-trust security architecture
/FORMAT: SWOT table, followed by a one-line go/no-go recommendation
/GUARDRAIL: No generic definitions of "zero-trust" — assume the reader already knows what it is. No emojis.
```
**What to Observe:** Output should skip basic definitions (per the guardrail), go straight to the assessment, end in one clear recommendation line.
