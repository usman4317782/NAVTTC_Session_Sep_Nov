# n8n AI Automation — Assessment Bank (10 Scenarios)

All assessments below share the same constraints:

- **Duration:** 1.5 hours each
- **Cost:** $0 — n8n Free 14-Day Trial + free-tier LLM APIs (Google Gemini free tier, OpenRouter free models, or Hugging Face free inference) only. No paid tools, no paid integrations.
- **Node budget:** ~10–13 nodes max — focused builds, not sprawling pipelines.
- **Deliverables:** `workflow.json` + execution screenshot + `writeup.md` (max 300 words) for each.
- **Passing threshold:** 70% per rubric.

Each scenario is drawn from a different real-world domain and teaches a distinct AI-automation engineering pattern — no two assessments repeat the same core skill.

| # | File | Domain | Core Pattern Taught |
|---|---|---|---|
| 1 | `01_support_triage_quality_gate.md` | Customer Support | AI self-review / quality-gate loop |
| 2 | `02_job_application_screener.md` | HR / Hiring | Explainable, grounded AI scoring (no black box) |
| 3 | `03_personal_finance_digest.md` | Personal Finance | Reasoning across a dataset + anomaly detection |
| 4 | `04_content_moderation_pipeline.md` | Trust & Safety | Tiered severity classification + confidence-based override |

| 10 | `10_multilingual_feedback_router.md` | Global / i18n Support | Chained translation → independent urgency analysis |

## How to Use This Bank

- **For instructors:** assign one scenario per student/cohort to avoid duplicate submissions, or rotate scenarios across assessment cycles.
- **For students:** each file is fully self-contained — scenario, constraints, step-by-step guidance, deliverables, and rubric all included. Pick one and follow it end-to-end.
- **For portfolio building:** completing even 2–3 of these gives a candidate a genuinely diverse, demonstrable n8n + AI automation portfolio spanning support, HR, finance, safety, sales, content, and engineering use cases — all built and verifiably run at zero cost.
